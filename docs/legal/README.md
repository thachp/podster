# Legal and policy drafts

**Proposed, for the owner.** These are drafts for [M4 step 3](../m4-plan.md#build-order). By [decision 167](../spec/PRODUCT.md#decisions-needed) the owner approves this text, and it may need a lawyer before anyone outside the project relies on it. None of it is published, and nothing in the app links to it yet.

| Draft | What it covers |
| --- | --- |
| [Terms](terms.md) | What Podster is, what it does and doesn't do, accounts, content, public rooms, the preview, and the parts only a lawyer should write |
| [Acceptable use](acceptable-use.md) | What isn't allowed, and what Podster can do about it |
| [Takedown](takedown.md) | How to report something, and the contact that's still a placeholder |

The drafts follow two rules:

- **No promise the code doesn't keep.** Each statement is checked against the specs and decisions it cites. Where something isn't built yet, the draft says so or leaves it out.
- **Export stays deferred.** [Decision 59](../spec/PRODUCT.md#decisions-needed) deferred export, and [decision 167](../spec/PRODUCT.md#decisions-needed) keeps it deferred until production, so the drafts promise no export.

Text in `[square brackets]` is a placeholder for the owner or a lawyer.
